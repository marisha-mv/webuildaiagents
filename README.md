# We Build AI Agents - Brand Showcase

Modern SaaS brand system with purple/pink gradient aesthetic.

This is the brand showcase website for We Build AI Agents, deployed via GitHub Pages.

## Local Development

Simply open `index.html` in your browser or use a local server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server
```

Then visit `http://localhost:8000`

## Deployment

See `DEPLOYMENT.md` for detailed deployment instructions.

Quick deployment:
1. Repository already exists at https://github.com/marisha-mv/webuildaiagents
2. Run `./push-to-github.sh`
3. Enable GitHub Pages in repository settings
4. Configure DNS if using custom domain

## Files

- `index.html` - Main brand showcase file
- `CNAME` - Custom domain configuration for GitHub Pages (if needed)
- `DEPLOYMENT.md` - Detailed deployment instructions
- `push-to-github.sh` - Script to push to GitHub
